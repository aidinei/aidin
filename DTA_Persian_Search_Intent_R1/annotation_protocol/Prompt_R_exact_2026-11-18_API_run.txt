RECOVERED SCHEMA DECISION RULES (verbatim preserved text):
Single-label decision rules for Persian search intent annotation
=================================================================

Decision priority for ambiguous single-label assignment: (1) Navigational if the query is primarily a named entity/brand/site; (2) Transactional if an explicit conversion action is present; (3) Local if location/service discovery is the main signal; (4) Commercial if price/comparison/provider evaluation is main signal; (5) Informational otherwise. Mark ambiguous=yes when two labels remain plausible after applying the priority rule.

Informational: Use when the query primarily asks for a definition, explanation, rule, date, comparison, or general knowledge. If a query asks "what is", "how", "rules", "difference", or informational program details without direct action, assign Informational.
Commercial: Use when the query primarily compares providers/products, asks for cost/price/fees, best options, materials, suppliers, or evaluation before a possible transaction. If price/evaluation is present without a direct action verb, Commercial has priority over Informational.
Transactional: Use when the query expresses an action or conversion intent such as registration, application, purchase, reservation, order, appointment, or direct service acquisition. Action verbs such as "ثبت نام", "خرید", "رزرو", "درخواست", "اپلای" usually trigger Transactional unless the query clearly asks only for information.
Navigational: Use when the query seeks a known website, brand, organization, university, product page, or named entity. A pure brand/institution/domain name is Navigational even if it belongs to a local institution.
Local: Use when the main intent is finding a service/place in a geographic location, city, district, or local institution context. If a query contains a location plus a service/product but no explicit purchase/action, Local is preferred over Commercial.
